# Camera-ready manuscript

- [RTD-AIMS-COLM2026.pdf](RTD-AIMS-COLM2026.pdf): the October 2, 2026 camera-ready revision for the AI Measurement Science Workshop at COLM 2026: nine pages of main content, references on pages 9–10.
- [camera-ready-source.zip](camera-ready-source.zip): matching LaTeX source, official COLM style files, abstract, and the figure script with its data. Unzip and run `make` with TeX Live and `latexmk`; `python figures/make_figures.py` (matplotlib, LaTeX) regenerates Figures 2–3.

- [RTD-extended-preprint.pdf](RTD-extended-preprint.pdf): the 22-page extended preprint (formal contract, proofs, detailed methods, capture cost, query scaling). Its numerical package is in [`../experiments/paper_evidence/`](../experiments/paper_evidence/).

The repository link appears on the paper's first page. This is the AIMS workshop manuscript, not the separate extended arXiv draft.
